# YouTranslate

Firefox extension that translates available YouTube captions and speaks the translated lines using the browser's built-in speech synthesis.

## Current prototype (0.1.3)

- Adds a floating **Перевод голоса** panel on YouTube watch pages.
- Lets you choose a target language.
- Loads caption tracks exposed by YouTube, including its automatically speech-recognized (`asr`) tracks when available, translates the lines, and speaks them approximately in sync with playback.
- Uses the browser's installed voices for speech output.

## Install in Firefox (temporary)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…**.
3. Select the `manifest.json` file from a downloaded copy of this repository.
4. Open a YouTube video with captions and click **Перевод голоса** in the bottom-right corner.

Temporary add-ons are removed when Firefox restarts. For normal distribution, the extension must be packaged and signed for Firefox.

## Current limitations

- This is an early prototype, not a full replica of Yandex's dubbing system.
- It can use YouTube-generated automatic captions when YouTube provides an `asr` track, even if the creator did not add subtitles manually. It still cannot transcribe raw video audio when YouTube exposes no caption track; a dedicated ASR engine and audio-processing pipeline are needed for that.
- Speech is generated by the browser and may sound different from the original speaker. Voices depend on the operating system and installed speech engines.
- Translation currently uses Google's publicly accessible web translation endpoint, which is unofficial and may be rate-limited or change without notice.
- Timing is caption-based. Speech uses a sequential queue so a new caption no longer cancels the line currently being spoken; short queue overflow is merged instead of overlapping, stale queued lines are discarded, and caption gaps do not cut speech off. Playback pause/resume and seek detection are handled, and speech rate is adjusted to fit caption windows. Long lines can still lag because browser speech synthesis does not expose reliable word-level timing.
- Video and translation service availability can vary by region/network.

## Planned improvements

- A dedicated audio transcription (ASR) engine for videos where YouTube provides no caption track.
- Better queue/timing management and pause/resume behavior.
- Optional translation provider configuration and clearer error reporting.
- Signed Firefox package after testing.
